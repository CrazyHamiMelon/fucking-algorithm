# 🎨 贺卡订制系统

一个基于Fabric.js的在线贺卡订制工具，支持图片上传、文字编辑和富文本功能。

## ✨ 核心功能

### 🎯 贺卡定制
- 点击"开始定制"按钮启动编辑模式
- 支持上传背景图片作为贺卡底图
- 背景图片自动适应画布大小，不可编辑和选中

### 📸 图片管理
- 最多支持上传5张装饰图片
- 每张图片支持以下操作：
  - **旋转**：点击左上角绿色按钮进行15度旋转
  - **缩放**：点击右上角黄色按钮进行等比缩放
  - **删除**：点击右下角红色按钮删除图片
- 图片支持拖拽移动
- 控制按钮精确定位，跟随图片四个角旋转

### ✍️ 文字编辑
- 最多支持添加3个文本框
- 双击文本框打开富文本编辑器
- 支持以下文字格式：
  - 字体选择（Arial、Times New Roman、微软雅黑、宋体等）
  - 字体大小调节（8-72px）
  - 字体颜色选择
  - 粗体、斜体、下划线
- 支持部分文字选择编辑
- 文字之间相互独立，可设置不同样式

## 🚀 快速开始

1. 在浏览器中打开 `index.html`
2. 点击"开始定制"按钮
3. 上传背景图片作为贺卡底图
4. 添加装饰图片和文字
5. 使用各种工具进行编辑

## 🏗️ 技术架构

- **前端技术**：HTML5 + CSS3 + JavaScript ES6+
- **画布库**：Fabric.js 5.3.0
- **富文本编辑**：contenteditable + document.execCommand
- **响应式设计**：支持移动端和桌面端

## 🎯 操作说明

### 开始使用
1. 打开页面，点击"开始定制"按钮
2. 系统会提示上传背景图片
3. 选择一张图片作为贺卡底图

### 添加装饰图片
1. 点击"上传图片素材"按钮
2. 选择要添加的图片文件
3. 使用四角控制按钮调整图片

### 添加文字
1. 点击"编辑文字"按钮
2. 双击文本框进行编辑
3. 在富文本编辑器中设置文字格式
4. 点击"应用"保存更改
